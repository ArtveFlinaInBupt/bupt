# Bigdu University Problemset Template

大邮集集模板是一个用于排版套题题集的 Typst 模板。它脱胎于《大邮数学集》——欢迎使用大邮集集模板创造更多作品！

## 用法文档

需要编写一定量的样板代码才能正常使用这个模板，文档 WIP。

可参考[大邮化学集](https://github.com/ArtveFlinaInBupt/bupt-example-chemistry)的代码。大邮化学集是一个专为大邮集集模板编写的示例，其虽没有自然语言解释，但作为一个能实际编译的示例具有相当的价值——你甚至可以直接复制它的代码到新项目中以开始编写一本新书。
